# SVG Explorer — interactive Kivy SVG demo for kivy-ios 3.0

A richer Kivy app than [hello-kivy](../hello-kivy/README.md). It renders vector
drawings with Kivy's SVG engine and lets you manipulate them with multitouch:

| Gesture / control | Action |
|-------------------|--------|
| drag              | pan the drawing |
| pinch (2 fingers) | zoom |
| twist (2 fingers) | rotate |
| **Prev / Next**   | cycle through the bundled SVG drawings |
| **Reset**         | fit the current drawing back to the view |
| **BG**            | toggle the background (dark / light) |

The drawings live in [`src/assets`](src/assets/) (`star.svg`, `heart.svg`, and a
gradient-filled `hexagon.svg`) and are loaded by path at runtime, so they ride
into the app bundle through the generated `app/` source link.

Uses the official **python.org** iOS `Python.xcframework` preview (**3.15.0b2**)
and, like hello-kivy, **Path A**: locally built `cp315` Kivy iOS wheels in the
shared [`examples/wheels/`](../wheels/) directory, pinned by `toolchain lock`.

## Prerequisites

- macOS with Xcode (same as [hello-world](../hello-world/README.md)).
- kivy-ios 3.0 installed from this repo (`pip install -e ".[dev]"`).
- Kivy `cp315` iOS wheels in [`examples/wheels/`](../wheels/). Build them once
  from the repo root (see
  [hello-kivy → "Build iOS wheels locally"](../hello-kivy/README.md#1-build-ios-wheels-locally));
  both Kivy examples share the same directory via `find_links = ["../wheels"]`.

If wheels are missing, `toolchain doctor` reports which `find_links` directory
is absent or empty before `toolchain lock` reaches pip.

## Lock, build, run

```bash
cd examples/svg-explorer
toolchain lock --update
toolchain build --simulator
toolchain run --simulator
```

`[tool.kivy.ios].find_links = ["../wheels"]` tells `toolchain lock` to resolve
Kivy from the shared vendored directory; the lockfile records `path` + SHA-256
for each local wheel slice.

You can also open the project in Xcode and press Run:

```bash
toolchain open
```

## Run on desktop first (optional)

It's a standard Kivy app, so you can sanity-check the UI on your Mac before
bundling (in a Python env that has desktop Kivy installed):

```bash
python examples/svg-explorer/src/main.py
```

## Files

| Path | Purpose |
|------|---------|
| `pyproject.toml` | App config + `find_links` for shared vendored wheels |
| `src/main.py` | Interactive `Scatter`-based SVG viewer |
| `src/assets/*.svg` | The vector drawings rendered by the app |
| `../wheels/` | Shared locally built Kivy iOS wheels (gitignored `.whl` blobs) |
| `pylock.ios.toml` | Generated by `toolchain lock` |
| `svg-explorer-ios/` | Generated Xcode tree (gitignored; recreated by `toolchain build`) |
